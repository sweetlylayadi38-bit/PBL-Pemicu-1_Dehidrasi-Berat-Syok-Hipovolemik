# Dehidrasi Berat & Syok Hipovolemik

Halaman scrollytelling untuk makalah PBL Pemicu 1: tata laksana awal dehidrasi berat dan syok hipovolemik.

**Buka halaman:** https://sweetlylayadi38-bit.github.io/PBL-Pemicu-1_Dehidrasi-Berat-Syok-Hipovolemik/

## Isi

1. Kompartemen cairan tubuh
2. Respons haus
3. Respons homeostasis
4. Dehidrasi berat: Rencana Terapi C WHO
5. Syok hipovolemik

Daftar referensi lengkap ada di bagian bawah halaman.

Mindmap makalah (PDF): https://sweetlylayadi38-bit.github.io/PBL-Pemicu-1_Dehidrasi-Berat-Syok-Hipovolemik/mindmap.pdf

## Teknis

Satu file `index.html` tanpa build step. Animasi memakai GSAP 3.12.5 + ScrollTrigger (CDN), font dari Google Fonts. Gambar latar: `latar-ginjal.jpg`.

Menjalankan secara lokal: buka `index.html` di browser, atau `python3 -m http.server` lalu buka `http://localhost:8000`.
